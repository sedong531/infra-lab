# infra-lab

가상 환경에서 보안 인프라를 구축하고 운영하는 프로젝트입니다.

## 목표
- pfSense 구축
- 내부 네트워크 구성
- IDS/IPS 적용
- SIEM 구축
- 공격 및 탐지 실습

## 사용 기술
- Vmware Workstation
- pfSense
- Linux Server
- Windows
- Suricata
- Wazuh(예정)
